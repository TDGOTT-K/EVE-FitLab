# 情景设置第一轮实现

2026-09-17。本地设计基线提交：`5c58727`。

## 已实现

- “情景设置”替换靶标入口，即使计算服务不可用也能打开。
- 轻量二维平面：本舰居中，右键放置目标、传电来源、毁电来源，从本地装配中选择；右键对象更换或移除，拖动位置调整距离。目标沿用相对速度箭头与防御层选择。
- 每份装配可新建、命名、复制、删除、保存多个情景；工作区直接选择情景或“不应用情景”。单情景旧数据首次读取迁移为“原有情景”。
- 独立保存接口只更新所选装配的情景字段与版本，不顺带保存装备草稿；保存失败保留编辑内容，陈旧版本拒绝写入。未保存的新装配需先保存一次以获得本地身份。
- 情景区只配置条件，不再重复展示输出结果。情景未保存改动在小窗内切换时保留，关闭时可确认放弃。
- 图片分享入口移除情景及本地多情景字段，使用无情景装配计算报告；移除图片正文原先的目标、传电与毁电来源展示。装配码仍不携带情景。

## 本轮边界

当前每个情景支持一个目标、一个传电来源、一个毁电来源。沿用既有静态计算：来源持续工作，尚未计算来源缺电导致停机；小窗已明确提示。

全工作区情景数值映射、升降颜色、总 DPS 的 Tab 曲线与当前 X 坐标、新引擎接入，以及更完整的传电/毁电模型尚未在本轮实现。目标速度仍为已有的相对速度矢量，不宣称已完成双方独立速度模型。未重新打包 Windows 安装程序。

## 第二轮：画布内呈现

按用户反馈移除底部文字与控制区。情景选择、图标管理、保存集中在顶部一行；重命名就地编辑，不再占单独一行。距离贴近连线，速度跟随箭头，角速度与紧凑防御层贴近目标；来源只显示舰型和作用，完整装配名在悬停提示中提供。比例尺、复位和按需展开的帮助位于画布角落。停止/横向飞行移入目标右键菜单。

修复目标图标缺少命中区域导致拖动/右键不可靠的问题；视角变化不再标记情景未保存。保持既有持久化和计算接口。

使用独立 QA 数据验证真实鼠标拖动与右键、键盘菜单、停止/横向飞行、重命名、新建、情景切换、保存重开与复位不改脏状态。1440×1000 和 1040×760 截图分别为 output/playwright/scenario-canvas-v2.png、scenario-canvas-v2-small.png。JS 语法及差异检查通过。本轮未改计算规则或重新打包安装程序。
