# 情景工作区数值与升降颜色

2026-09-17。基于现有静态引擎的第二轮 UI 接入，不是 N 号引擎迁移。

## 行为

- 工作区顶部显示当前情景和计算状态。选择情景后，武器装备行、右侧攻击汇总、分伤害类型、电容及持续维修采用同一份情景响应。
- 同一次已求值配装生成无情景基准，不重新创建另一份配装来比较。数字比基准降低为红色，升高为绿色，不变保留原色；颜色不代表好坏。
- 武器 DPS 使用目标几何、签名及抗性后的期望输出，不含换弹；含换弹 DPS 单列。总 DPS 移到“攻击”标题旁。每件武器保留其实际槽位、弹药身份和独立分项。
- 检查器结果与可见值保持一致，提供无情景基准、分项和计算条件。物品详情中的武器 DPS、齐射及伤害分量亦采用同一情景应用数据。
- 传电/毁电显示在本舰电容区；净耗电包含本舰消耗、吸电、注电、受到毁电和友方传电。修正旧计算中净耗电未包含外部传电/毁电的问题。
- 电容续航只有同为耗尽时间或稳定区间等可比数值时做数字比较；不同文字状态不强行折算为虚构数值。CPU、PG、抗性等不受当前情景条件改变的属性仍保持装配自身值。
- 不应用情景恢复中性数值及正常颜色。计算中/失败时隐藏过期数字，关闭旧检查器；过时响应仍由请求版本门禁丢弃。
- 图片分享仍清除情景并单独生成中性报告，不输出本地情景结果。

## 未支持范围

- 当前旧引擎未提供完整无人机目标应用。存在出动无人机时，目标情景中的无人机 DPS、总 DPS 和含换弹总值显示不可完整计算；保留可计算的武器分项，不把未知当作零或理论无人机输出。
- 未支持武器应用同样明确显示缺失，不将部分武器的求和冒充全船输出。
- 外部电容来源仍假设持续工作，尚未联算来源缺电停机。导弹暂沿用情景相对速度作为近似，未接入独立的目标绝对速度。检查器披露上述条件。
- 时间轴仿真、DPS 函数图与 Tab 切换不在本轮实现。

## 验证

- `python -m unittest test_workspace_view test_scenario test_capacitor test_linked_scenario test_server -q`：27 项通过。新增独立算例覆盖应用系数与抗性、换弹、齐射、槽位/汇总一致、无情景基准、未知无人机与武器不报零、同名模块不同数值。
- `node test_fit_image_code.mjs`：分享隔离及编解码回归通过。修改的 JS 语法与差异检查通过。
- 实际旧引擎配装使用两件 125mm Gatling AutoCannon I，分别装 EMP S、Phased Plasma S，以及 Small Armor Repairer I。无情景武器 DPS 16.5，选定近距离目标后 13.809767；装备行 7.393108 + 6.416659 与汇总一致，检查器显示 13.81。
- 传电情景净耗电 6.666667 → 0.666667 GJ/s，电容由 84 秒耗尽变为稳定；毁电情景净耗电 14.166667 GJ/s，30 秒耗尽。红绿方向和取消情景后恢复均经过 DOM 与实际页面核对。
- Playwright 的延迟响应与故意失败测试验证：旧情景迟到响应不覆盖最新结果，加载/失败时旧数字不可见，重新选择情景后可恢复。
- 实验使用独立端口 5209、`output/workspace-qa` 数据，不改用户正在试用的装配。脚本位于 `output/playwright/verify-workspace-values.js`、`verify-workspace-race.js`。
