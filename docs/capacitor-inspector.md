# 电容检查器

悬停“电容续航”或“净耗电”打开专用面板。先显示稳定区间、首次无法支付启动耗电的时间，或已检验但未确认稳定的时间；随后显示电容百分比随时间曲线和有效收支。无情景不显示基准说明；有情景显示当前情景和无情景的结论对照。

曲线直接记录 `calculate_capacitor` 的同一次周期模拟。样本包含时间、回充后电量、周期处理后的电量，以及可用时的本舰扣电后电量。保留同刻先支付本舰耗电、再接受外部收益的顺序。满电起步；终点为首次不能支付模块启动耗电，未必是电容归零。稳定结果画到相位收敛，未确认稳定结果只画到实际检查终点。

时间序列采用逐步降低采样频率的有界缓存，约 1024 个样本；长时间曲线不保证保留每次脉冲，样本之间用折线连接。数值判定仍使用全部原始事件，不受绘图采样影响。被动装配显示满电水平线。

收支只显示非零值：自身峰值回充、模块耗电、吸电、注电、外部传电、受到毁电。明确峰值回充并非实际恒定收入；收益与耗电为周期平均值。注电计换弹并假设持续补弹；外部来源假设持续运转，只判断当前装配。毁电已计本舰电容战抗性。

面板无嵌套属性，不引入锁定或锁定动画。鼠标可直接移入曲线查看时间、电容百分比和 GJ。离开关闭，Esc 关闭。数据随工作区计算一同更新，沿用旧结果失效处理。

验证：40 项相关 Python 测试通过；新增覆盖周期采样、同刻收支、终点、被动曲线、稳定最低电量及长序列上限。浏览器验收无情景、传电、毁电、曲线探查、不锁定以及 1440×1000、1040×760 布局。
