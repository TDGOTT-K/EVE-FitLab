# 脑插与增效剂方案 UI 原型

角色管理新增“角色技能 / 脑插与增效剂”入口。方案库独立保存命名方案、分组、脑插槽位、药剂及固定副作用选择；支持搜索、复制、删除、列表 Ctrl+C/V、草稿恢复。

装配页通过驾驶员旁的入口选择方案，保存 `loadoutPlan` 快照。方案库后续保存不会改动装配，重新选择或“应用到装配”才会更新，可撤销。原 `implantPlan` 保留并可带入管理器保存为独立方案。删除库中方案不删除装配快照。

本阶段不计算加成、技能门槛、随机副作用或药效计时。目录使用随项目提供的 SDE 3248221 元数据（脑插属性 331、增效剂属性 1087，副作用取有 fittingUsageChanceAttributeID 的效果），不代表 N 引擎最终数据版本。新引擎接入时需通过适配器校验物品、槽位及效果。

本地存储：library.loadoutPlans，独立 revision 并发校验；GET /api/loadout-plans，POST /api/loadout-plan 和 /api/loadout-plan/delete。

验证：Python 保存隔离、revision 冲突及无效槽位/副作用测试；独立 5209 浏览器验证添加脑插与药剂、选择副作用、保存、装配调用、快照隔离、明确更新、撤销、更新标记、复制、刷新恢复草稿、删除和 920×650 滚动布局。

## 常驻物品浏览器

左栏上方保留方案库，下方为常驻脑插/增效剂浏览器。使用 SDE 物品组与槽位分类、名称/英文型号搜索；点击方案槽位筛选兼容物品。单击或拖入对应槽位安装，同槽替换；拖至编辑区空白位置自动装入所属槽位；已安装条目拖回浏览器卸下。错槽拖入不产生修改。相同物品重复安装不清空已选副作用。

验证：独立浏览器检查点击安装、槽位筛选、正确槽位拖入、错误槽位拒绝、拖回卸下、药剂选择、保存，以及 958×912、920×650 布局。

方案库现移至工作区顶部并横跨全宽；下方物品浏览器与装配编辑区左右并排。点击“方案库”折叠/展开，折叠后保留当前方案名及新建入口，状态在本地记忆。已检查展开/折叠的区域对齐、刷新恢复状态和小窗口搜索筛选。

## 按增益分类

分类生成脚本 scripts/build-loadout-benefits.py 使用随项目 SDE 的 Dogma 属性、套装标识和物品说明，生成 benefitPaths/benefitLabels。多个增益允许跨分类出现；搜索结果按物品唯一，类别计数去重。槽位仅作兼容性筛选。纯属性点脑插需同时满足：有属性点、无其他非元数据属性、只有属性点效果，才归入“训练与其他 / 白板”。套装及 Omega 按套装实际作用分类；药剂 penalty 属性排除。条目显示增益名称，白板显示准确属性点；不提供未经适配的战斗加成计算值。特殊或资料不足条目保留“其他特殊效果”。

验证：白板/混合脑插互斥、极乐/蝰蛇/护符全套（含 Omega）、蓝色药丸副作用排除、目录覆盖及分类去重；浏览器展开分类、白板搜索、别名搜索、搜索去重、选药与槽位筛选。
