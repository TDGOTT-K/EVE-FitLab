# 2026-09-20 安装、移除和预览性能

当前独立引擎0.210.4-ui.perf1，契约保持r57-ui-affixes1，静态v59/SDE3503375。仅当前副本，主引擎与历史副本未修改。

## 修改

1. 引擎SDE缓存避免全技能输入挤出静态定义；完整分析结果按源、输入和上下文缓存，返回独立对象。上游补丁LOCAL-013。
2. 悬停使用公开fit_analyze的完整候选分析；展示仍是原值→候选值，不在UI生成独有业务差量。实际编辑继续走原生prepare/preview/create/execute及完整哈希验证。公开/api/preview仍保留原生预览供调用。
3. 同一装配/目标槽/物品/深渊实例/攻击口径共用候选快照（含新晶体身份）与结果。12项有界缓存，失败可重试；所有调用方拿独立候选副本。悬停后安装不再重算同一候选。链接情景的分析仍不缓存。
4. 预览最多一个在途任务，过期等待者不继续计算；hover防抖150ms、drag100ms。已有在途请求不强制中断引擎。
5. 晶体默认装填不再多算一次弹仓容量；普通弹药容量仍由引擎查询。
6. 编辑期间可继续浏览与选择，保留事务忙/待确认时的修改保护和重试，不再令整个编辑区inert。
7. HTTP业务响应紧凑JSON+协商gzip；事务receiptOnly只缩减传输中的analysis为fitHash，版本/命令/准入/错误/回执不变。默认接口仍完整；公开MCP/CLI未删字段。

## 同机测量

隔离浏览器，不保存/覆盖用户装配。Phantasm17718，3×Heavy Pulse Laser II3520，Scorch M12818换Conflagration M12814，独立晶体，全V511技能，不应用情景。下面是浏览器resource timing；毫秒不是普适保证。

|请求|修改前|修改后热态|
|---|---:|---:|
|候选完整分析|1226～1416ms，约2.14MB|约656～669ms，gzip约211KB|
|悬停预览|2270～2579ms，约5.87MB|共用上述候选分析；无需重复基准分析|
|原生preview-input|1203ms，3.71MB|317～518ms，简要回执约3KB|
|原生execute|903ms，1.86MB|115～287ms，约6.5KB|

重复悬停含UI更新实测239ms；预览后安装无新增/api/analyze。移除单件至提交确认实测922ms（含自动化点击等待），画面先更新。首次新配置悬停到展示仍约1.3秒，不能用缓存命中时间代表首次计算。估价外部查询曾出现5.7～7.5秒，独立异步接口；未将其冒充已优化或当作0价格。
