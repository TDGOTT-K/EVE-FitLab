# 下载中心

顶部设置左侧的下载图标打开最近四项任务的 popover，底部链接进入独立下载中心界面；返回或顶部导航关闭中心，不改变正在编辑的装配。中心支持名称搜索、状态筛选和清理已结束记录。移除记录不删除文件。

所有现有用户文件导出入口（装配 EFT、完整装配 JSON、装配 PNG、脑插方案文字及 PNG）统一调用 `saveDownload`。浏览器记录“已交给浏览器保存”，不推断落盘结果；当前页面保留最近二十份导出的再次保存能力。刷新后保留记录但不保留文件内容。

桌面通过 Electron `will-download` 跟踪文件真实状态；支持下载进度、暂停、可恢复时继续、取消、完成后定位文件。记录存储在应用本地根目录 `downloads.json`，重启后未完成的任务标记已取消，不虚构断点续传。

更新由现有签名校验控制器提供状态，中心负责下载、取消、重试及保存后安装。设置页保留检查与中心入口。安装步骤继续使用原有备份及保存流程，不自动重启。公告仍先打开更新设置，确认有更新后自动进入中心下载。

- `node test_desktop_updates.cjs`：原有签名/哈希/保存验证，加上取消下载。
- `node scripts/check-ui.cjs`：85 个浏览器模块。
- Playwright：1045×912 下小面板与完整中心、文件真实导出、搜索、记录持久化、清理及导航；桌面更新接口模拟验证下载后等待安装。
- 真实 Electron 独立测试：`output/playwright/download-electron-state/result.json`，导出 blob 内容核对成功且记录为 completed。首次测试脚本错误引用 npm Electron 入口造成弹窗，已关闭测试进程并改为内置 `require('electron')`，重跑退出码 0。
