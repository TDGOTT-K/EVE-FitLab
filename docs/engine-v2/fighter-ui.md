# 铁骑舰载机 UI 原型

状态：待用户评审，UI mock，未接入 N 号引擎。

航母和超级航母在中间舱室区域使用发射管和备用机库替代普通无人机库。点击发射管筛选左侧浏览器；双击或拖入安装；中队之间交换，空位移动，拖回浏览器卸下。支持数量、参战状态、撤销/重做、装配草稿保留。

当前仅有轻型、重型、支援三个示例中队，SVG 为类别占位图。发射管数量、中队规模、支援上限均为原型规则，不能作为游戏机制或引擎能力保证。尚未实现真实机库体积限制、型号列表和技能状态。

数据保存在独立的 fighterUiMock 字段；不进入旧引擎无人机数据，也不贡献右侧 DPS。正式接入时必须按引擎接口复核限制，并二次设计技能、机库容量与输出状态。

验证：独立浏览器中验证夜神级五个发射管、浏览器安装、数量修改、移动、交换、备用、卸下、撤销和刷新恢复。截图见 output/fighters/workbench.png。
