# 2026-09-19：刷新性能修复与测量

本批不改界面布局，不改游戏规则或独立引擎代码。公开契约保持 0.190.8-ui.1 / r41。

## 已修改

- MCP 适配层只缓存包含完整 fit 快照的 fit_analyze、fit_preview_input、fit_attributes、capacitor_scenario。完整方法名及请求 JSON 为键；输入或分析上下文变化即重新查询。缓存最多 48 项、16 MiB，进程启动/关闭清空；返回独立反序列化副本，保留 null、诊断、来源。会话读写、随机、价格不缓存。
- 固定服务进程内的装备/脑插目录使用 gzip、ETag 和条件请求；静态资源允许重新验证。业务 API 仍不允许浏览器缓存。
- 简体中文不构造无用翻译正则、不监听全部 DOM 变化；切换语言仍执行翻译恢复。
- 页面入口的语言、装备目录和市场图标加载改为并行。

## 实测范围

本机 5208，固定引擎副本，未修改用户装配数据。HTTP 分析样本：shipId=587，high-0 安装 2881，ammo=185，Active，内置 all5 技能。

| 项目 | 修复前 | 修复后 |
|---|---|---|
| 同输入重复 HTTP 分析 | 1.035 / 1.022 / 0.997 秒 | 0.130 / 0.054 / 0.143 秒 |
| 装备目录传输体积 | 8,878,847 字节 | gzip 836,242 字节；ETag 命中 304 无正文 |

重复分析解码后的完整响应一致。首次分析仍需要真实计算，未宣称冷查询具有上述加速。

浏览器以“赫卡特级 · 新装配”中实际出现 468.3 DPS 为就绪条件，测量 reload 调用到 DOM 就绪（包含自动化开销）。最终三次热刷新 773 / 804 / 798 ms。服务重启后单次完整刷新为 6,891 ms：冷启动仍需继续优化。没有可靠的修复前整页同条件样本，不能将 HTTP 查询加速倍数当成整页加速倍数。

## 验证与后续

- 2 项缓存回归通过：完整输入与上下文隔离、嵌套结果隔离、null、非缓存会话接口、容量上限、错误重试。
- 真实引擎 native-edit-history 回归通过：安装/撤销/重做、空变更、会话归属、丢响应恢复。
- 60 个浏览器模块静态检查通过，实际页面数值恢复正常。
- 本批未解决冷启动、不同输入首次计算和原生编辑事务的全部延迟；未重做用户指出的其他 UI 退化。
- 之前 Windows 安装包不包含本次修复，尚未重新打包。
