# EVE FitLab 0.1.2-rc.1 · 第二个公开测试版 / Second public test release

发布日期：2026-09-20。保留已冻结安装包的版本号 0.1.2-rc.1，这是第二次公开测试发布，尚非稳定版。

## 下载 / Download
- Windows 10 / 11 x64，安装包 208.2 MiB，自带运行时和静态数据。
- 官网：https://imfishman.com/download#preview

## 本次更新
- 接入独立 N 号引擎，更新装配分析、属性详情与性能曲线。
- 加入舰载机、深渊装备、脑插与增效剂方案相关功能；部分机制仍有明确的不可用或部分支持提示。
- 更新装配库、保存与撤销/重做，以及装配和方案分享。

## 测试说明与已知限制 / Known limitations
- 安装包未签名，Windows 可能提示未知发布者；暂无自动更新。
- 重要装配请先备份。本版使用新的引擎状态目录，不自动迁移历史原生会话。
- 尚未在干净虚拟机或其他电脑完成安装和卸载验证。打包程序已完成真实分析、预览、安装提交、保存、撤销/重做与分享回归。
- 本轮未重新验证真实账号 SSO 登录，回调需要 5207 端口空闲。
- 首次新配置预览仍约 1.3 秒，外部估价可能更慢；部分机制为 partial/unsupported，不包含完整战斗时序模拟。
- Unsigned test release. Back up important fits. Clean-machine installation and live SSO have not been revalidated for this build.
