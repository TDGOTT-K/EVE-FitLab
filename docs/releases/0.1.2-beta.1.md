## EVE FitLab 0.1.2-beta.1 — 首个公开测试版 / First public beta

**这是测试版，不是稳定版。欢迎体验并反馈问题。 / This is a beta, not a stable release.**

### 下载 / Download

- Windows 10 / 11 x64：下载 `EVE-FitLab-0.1.2-beta.1-Windows-x64-Setup.exe`。
- 安装包自带运行时，无需另装 Python、Node.js 或 .NET。
- 官网与版本选择：[imfishman.com/download](https://imfishman.com/download)
- 文件大小：166.4 MiB。

### 本次包含 / Included

- 舰船装配、角色技能、性能计算和可视化靶标。
- 无人机与货舱、拖拽预览、整组操作、装配库及标签。
- 装配长图分享、二维码导入、简中 / 繁中 / English / 日本語。
- 本地数据管理、自定义 F 图标与官网入口。

### 测试版须知 / Beta notes

- **尚未支持铁骑舰载机（航母配置）与深渊装备系统。Fighters (carrier fitting) and Abyssal modules are not supported yet.**

- 安装包尚未代码签名，Windows 可能显示未知发布者。The installer is unsigned.
- 暂无自动更新；后续请从官网或 GitHub Releases 下载新版本。
- 可能存在计算或界面问题，重要配置请保留备份。
- EVE SSO 仍需真实账号端到端验证；战斗计算不包含完整时序模拟。
- 已在当前 Windows 主机验证安装、启动、真实装配计算、后台鉴权和卸载；不代表所有 Windows 环境的兼容性保证。
