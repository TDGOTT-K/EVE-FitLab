# EVE FitLab v0.1.3 · 公开测试版

- 新增应用内更新：检查官网签名清单、下载更新，保存并备份后重启安装。
- 新增公告系统：启动显示未读公告，设置中可重新查看；更新公告可直接开始更新。
- 新增下载中心：顶部小面板查看最近下载，完整中心管理导出文件及应用更新，支持搜索和状态筛选。
- 桌面文件下载支持进度、暂停、继续、取消与定位文件；应用更新支持取消下载与重试。
- 保留 v0.1.2-rc.6 的装填、情景速度、深渊定位、子系统槽位与舰载机修复。

Windows 10/11 x64，内置运行时及 Agent MCP/CLI。

从 v0.1.2-rc.6 或更早版本升级，需要下载此安装包并覆盖安装一次；旧版本不具备应用内更新入口。v0.1.3 开始可在下载中心管理后续兼容更新。引擎/数据来源变化时可能仍需手动升级。

安装包未做 Windows Authenticode 代码签名，系统可能提示未知发布者。重要装配建议保留备份。应用更新的签名清单和文件哈希校验不等同于 Windows 代码签名。

发布分类为公开测试版（GitHub Pre-release）。版本号与安装包保持不变；现有更新地址中的 stable 是 v0.1.3 已内置的技术路径，不代表正式发布，保留以免破坏已安装客户端的更新检查。
