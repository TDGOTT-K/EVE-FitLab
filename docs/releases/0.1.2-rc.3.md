# EVE FitLab 0.1.2-rc.3 · 第四个公开测试版 / Fourth public test release

发布日期：2026-09-20。此版本为公开测试版，尚非稳定版。

## 本次更新
- 装配交互修复、深渊装备编辑与脑插方案汇总。
- 独立船舱分区。
- 加入六舰、100 秒战斗概念演示；这是概念演示，不代表完整战斗模拟功能已完成。
- 引擎更新至 0.210.6-ui.repair1，契约 r58-ui-mutation1，SDE 3503375。
- Fitting interaction fixes, abyssal editing, implant plan summaries, separate cargo sections, and a six-ship, 100-second combat concept demo.

## 验证与边界
- 随包记录：打包程序在独立测试目录通过原生计算、预览、保存、撤销/重做、后台鉴权，以及六舰演示 iframe 加载与退出导航。
- 77 个浏览器模块检查、11 项 Python 专项及 6 组 JS 专项通过。
- 桌面自动截图返回 UnknownVizError，未将其计为截图验收通过。
- 本轮未执行安装器安装/卸载或干净机器验证。安装包未签名；重要装配请备份。
- 不包含尚未验收的本地化并行修改，也不包含用户装配、角色授权或开发状态目录。
