# EVE FitLab v0.1.4 · 公开测试版

本版为公开测试版，GitHub 标记为 Pre-release。

- 修复退出装配编辑时意外保存，以及下载面板点击关闭后重新打开的问题。
- 完善角色技能界面：每级及累计加成悬停提示、等级连续高亮、分类技能点、I～IV 对比角色与官方前置技能补齐。
- 角色列表支持默认分组、按技能点初始排序和拖动排序。
- 新增 16 个内置 SVG 头像和自定义图片上传；头像保存在本机。
- 补齐角色与脑插方案的复制、粘贴和右键菜单，角色文件夹支持官网导入。

v0.1.3 可通过设置中的应用更新，或开屏公告的“立即更新”下载本版；安装仍需用户确认保存并重启。更早版本可下载安装包覆盖安装。

引擎保持 0.213.1-ui.charge1 / r62，未改变数据来源绑定。既有 `/updates/stable/` 是已安装客户端的技术更新地址，不代表本版属于正式发布。
