# EVE FitLab 0.1.2-rc.4 · 第五个公开测试版 / Fifth public test release

发布日期：2026-09-20。公开测试版，尚非稳定版。

## 更新
- 优化装配编辑响应，减少重复分析与不必要的界面重绘；属性详情按需加载，电容结果独立更新。
- 改善槽位预览、炮台/发射架数量、改装件数量与校准值，以及自动槽位放置。
- 修复制导计算机脚本处理，完善导弹射程、速度与曲线显示。
- 改善估价悬浮面板、物品参考价格和子系统技能特性展示。
- 引擎更新至 0.211.0-ui.workbench1 / r59-ui-workbench1，SDE 3503375。
- Faster fitting edits with less redundant analysis and rendering; improved slot previews, missile range displays, valuation panels and subsystem skill traits.

## 验证与边界
- 随包记录确认实际打包桌面的预览、应用、保存、撤销/重做通过；包内 CLI 导出一致，未授权请求返回 403。
- 本次发布校验已有安装包，不重新打包；不包含当前工作区未提交的本地化和其他开发修改。
- 冷启动与偶发耗时尖峰仍在优化，不承诺所有机器或所有装配达到相同速度。
- 安装包未签名；重要装配请备份。未追加执行干净机器安装/卸载或真实账号 SSO 验证。
