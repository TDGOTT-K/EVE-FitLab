# EVE FitLab 0.1.2-rc.2 · 第三个公开测试版 / Third public test release

发布日期：2026-09-20。此版本为公开测试版，尚非稳定版。

## 本次修复 / Fix
- 修复启动时界面加载时间过长、装配库迟迟无法操作的问题。
- 舰载机目录改为独立加载，不再阻塞主界面初始化；同时优化目录读取。
- Fixes excessive UI loading time at startup. Fighter catalog loading no longer blocks application initialization.

## 验证与边界
- 随包验证记录：同机单次对比，从启动到装配库可用由 12.86 秒缩短为 4.17 秒；这是单次样本，不代表跨设备性能保证。
- 已有打包程序验证覆盖分析、预览、安装提交、保存、撤销/重做与原生导出哈希一致。
- 引擎与 rc.1 相同：0.210.4-ui.perf1 / r57；保留第二个测试版功能。
- 本轮未重跑真实账号 SSO 或干净系统安装/卸载验证。安装包未签名，暂无自动更新；重要装配请备份。
- 部分机制仍为部分支持或不可用，不包含完整战斗时序模拟。
