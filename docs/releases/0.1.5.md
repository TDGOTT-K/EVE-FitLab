# EVE FitLab v0.1.5 · 公开测试版

- 修复应用更新在安装前备份时报“请求来源不匹配”的问题，补充主进程备份请求链路回归测试。
- 开发者介绍底部新增“不，我是来玩游戏的”按钮，在 App 当前窗口内启动“下班跃迁”小游戏，可随时返回 FitLab。
- 游戏模型与运行资源随安装包提供，无需额外运行本地服务。

**v0.1.3 / v0.1.4 用户请手动下载并覆盖安装本版一次。** 旧客户端自身的更新准备步骤有缺陷，重复点击应用内安装无法修复；本版修复后，后续版本可以使用应用内更新。覆盖安装前请保存装配并正常退出应用，不必卸载。

这是公开测试版（GitHub Pre-release）。引擎保持 0.213.1-ui.charge1 / r62。小游戏是街机彩蛋，不代表 EVE 实际作战机制。
