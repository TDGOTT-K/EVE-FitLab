# EVE FitLab 0.1.2-rc.6 · 第七个公开测试版

## 本次修复
- 自动锁定导弹可正常装填和计算；扫描探针按类型与容量验证，不再误走武器伤害计算。
- 情景支持本舰、目标两根独立速度箭头：导弹使用目标绝对速度，炮台角速度使用双方速度差。
- 深渊浏览器跳转后定位到对应装备；战略巡洋舰编辑刷新时保留子系统槽位。
- 舰载机校验异常可恢复：30秒超时取消、释放锁、保留配置，重试不复用挂起请求，迟到响应不会重复安装。

## 随包组件与验证
- Windows 10/11 x64，217.9 MiB；桌面与Agent采用0.213.1-ui.charge1 / r62修复引擎，使用独立状态。
- 内置FitLab Agent v7、MCP/CLI、skill与提示词，无需另装Python、Node.js或.NET。
- 包内桌面预览、应用、保存、撤销/重做、沙盒导航与CLI导出一致性通过；Agent通过实际DSH MCP插件及CLI一致性检查。
- 包含构建时已有的七语言本地化改动。精确包内来源见source-snapshot-manifest.json；开发基线adba8f9，引擎基线f01aab4。GitHub发布标签不单独代表所有构建时本地改动。
- 不含开发状态、角色授权令牌或个人装配库。

## 使用注意
这是公开测试版，尚未代码签名，暂不支持自动更新。升级前请备份装配数据；历史原生会话不自动迁移。自动锁定导弹选敌、探针扫描等未实现的战斗机制仍明确不可用。本轮未追加干净系统安装/卸载或真实账号SSO验证。
