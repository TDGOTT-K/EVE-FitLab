# 原位换装预览

选中单个槽位后，悬停装备浏览器候选 350 ms 开始预览；拖拽到兼容槽位停留 180 ms 同样预览。顶部短提示显示目标槽位序号、原装备与候选，目标槽位使用虚线高亮。

CPU、PG、攻击、属性行、标题摘要、伤害分量和已有装备槽数值在原位置显示候选计算结果。变化使用橙色预览强调，常规数值行显示旧值到新值；标题保持简洁。原节点、原事件处理及滚动位置保留，不生成第二套属性面板。

移开候选、结束拖拽、Esc、切换页面、修改装配或切换计算条件时恢复。预览只计算独立装配快照，不写装配、情景、保存状态和撤销历史。请求通过预览令牌与计算版本双重检查，过期结果不展示。计算失败时保留原值，并显示具体错误；引擎报告装配受限时展示问题。

安装与预览共用目标选择和替换逻辑。明确选中的槽位优先；多选不猜测目标，提示单选或拖到指定槽位。无选择时采用首个兼容空槽（弹药采用首个兼容装备）。明确选中但不兼容时不偷偷安装到别处。

替换装备保留兼容弹药及仍适用的启用状态，不兼容弹药会卸下并提前提示。双击、Enter 或拖放才进行实际安装，沿用一次撤销记录。当前仍调用既有计算链路，不代表已接入 N 号引擎。

浏览器验证覆盖：原位节点不替换、草稿与撤销历史不变、取消完整恢复、预览与实际安装一致、兼容弹药保留、换弹及 Enter、拖放、撤销、明确不兼容目标、延迟响应竞态、计算失败，以及 958×912 窄窗口。独立测试装配的换装算例为 16.5 → 17.49 DPS。

## 舰船图片快捷安装

拖入装备时忽略当前筛选或选中槽位，选择第一个兼容空槽；没有空槽不覆盖已有装备。拖入弹药仍批量装填兼容装备。

所有安装入口共用数量限制：使用引擎求值后的炮塔与发射器挂点、SDE 1544（maxGroupFitted）、2431（maxTypeFitted）。离线装备也计数，替换先扣除原槽位。计算尚未完成时暂不接受新的装备安装，避免使用旧上限。超限只显示原因，不修改装配或增加撤销记录。

验证：`test-installation-limits.mjs` 覆盖满挂点替换、零发射器、离线计数、跨型号同组上限、同型号上限。浏览器使用赫卡特级验证第五门炮成功、第六门炮拒绝、第二个损伤控制拒绝、零发射器拒绝、批量换弹与撤销。

## 已安装装备与弹药拖动

装备行与已装填弹药支持拖动。拖回左侧装备浏览器卸载；拖到兼容空槽移动，拖到已占用槽位交换。装备携带完整状态与弹药，槽位标识不交换。弹药单独拖动仅改变弹药。双方兼容性均检查；同槽位不操作。移动或交换不增加装备总数，因此满挂点允许正常调整位置。

每次成功操作只产生一次撤销记录，取消和拒绝不会写入草稿。安装来源与内部移动来源分开，内部拖动不会被舰船图片或货舱当作新增副本。浏览器验收装备移动、交换、弹药移动与交换、两种卸载、撤销、不兼容拒绝、取消拖动；纯函数用例验证反向兼容与状态保留。
